# 配置按修改时间同步

- 「自动保留最新配置」默认开启，按 Better Manager 记录的用户修改时间决定采用哪份配置。关闭后可查看差异并手动选择。
- 新配置停止写入修订代数，旧配置仍可读取。启动、升级、缓存维护和保存重试不会刷新用户修改时间。
- 同步指引提供可折叠、可复制的排除规则，支持打开同步插件设置并查看操作步骤。
- 「已设置，不再提醒」在当前设备生效，之后仍可从设置或命令面板打开指引。

## English

- Automatically keep the newest configuration by default, using the time Better Manager recorded the edit. Turn this option off to review differences and choose manually.
- New configurations no longer write a revision generation number. Older configurations still load. Startup, upgrades, cache maintenance, and save retries preserve the edit time.
- The sync guide includes collapsible, copyable exclusion rules and opens sync plugin settings with instructions.
- Use “Configured, don’t remind again” to dismiss advisories on this device. The guide remains available in settings and the command palette.
